## 🧠 How I Approach Troubleshooting

For each project, I document:

**Problem → Evidence → Diagnosis → Fix → Verification → Lesson Learned**

My goal is to understand **how and why a problem occurred**, identify the clues that point toward the cause, apply the appropriate fix, and verify that the solution worked.
